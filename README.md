# Guia Digital MPE

Cartilha digital interativa sobre transformação digital para micro e pequenas
empresas. O projeto apresenta conteúdos sobre ferramentas digitais e inclui uma
autoavaliação para ajudar a identificar oportunidades de melhoria.

## Tecnologias

- React
- TypeScript
- Vite
- Vitest e Testing Library

## Como executar

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

## Testes e validações

Execute os testes automatizados uma vez:

```bash
npm test -- --run
```

Execute a verificação de código:

```bash
npm run lint
```

Gere a versão de produção:

```bash
npm run build
```

Veja [TESTES.md](./TESTES.md) para um resumo dos testes e do que eles verificam.

## Páginas

- **Início** (`/`): apresenta a cartilha e seus conteúdos.
- **Transformação Digital** (`/transformacao-digital`): explica o conceito,
  benefícios e desafios.
- **Ferramentas Digitais** (`/ferramentas-digitais`): apresenta ferramentas
  para presença digital, comércio eletrônico e gestão empresarial.
- **Autoavaliação** (`/autoavaliacao`): questionário de nove perguntas que
  apresenta pontuações e classificações para três áreas.
